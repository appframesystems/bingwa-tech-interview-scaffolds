# Flutter Interview Scaffold

This is a minimal, working Flutter project designed for the pair-programming interview.

## The Brief

You have **15 minutes** of independent coding followed by **8 minutes** of integration with the backend.

### Requirements
1. **Create a Task**: Provide a text field and an "Add" button to create a new task.
2. **List & Complete Tasks**: Display the list of tasks. Each task should have a checkbox (or similar control) to toggle its completeness.
3. **Integration-Ready**: Build against your best guess of what the backend will require, structuring your networking/API service so it's easy to plug in a base URL and integrate with your partner's NestJS API during the integration phase.

## Packages Included
- `http`: Configured in `pubspec.yaml` for network requests.

## Getting Started

1. Open this directory in your IDE.
2. Run `flutter pub get` (if dependencies are not fetched).
3. Run the application on your choice of simulator or emulator:
   ```bash
   flutter run
   ```
4. Start implementing your code in `lib/main.dart` or feel free to structure it across multiple files.
